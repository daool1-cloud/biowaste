# Trained Machine Learning Models

The trained model files used in this study are
deposited on Zenodo.

## Download

Zenodo DOI: https://doi.org/10.5281/zenodo.24359465

## Model Files

- ESMC_600M_4cases_14algorithms.pth
- ESM2_t33_650M_4cases_14algorithms.pth
- ProtT5_XL_U50_4cases_14algorithms.pth
- ProtBERT_UniRef100_4cases_14algorithms.pth

## Installation

1. Download the four model files from Zenodo.
2. Place the files in the models/ directory.
3. Follow the instructions in the main README.md
   to install dependencies and run the pipeline.
